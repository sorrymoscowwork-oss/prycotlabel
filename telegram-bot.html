PRYCOT. / TELEGRAM BOT GUIDE

Submit your release correctly. Every detail matters.

PRYCOT. uses an official Telegram bot to collect release information and prepare your submission for distribution. Follow the steps carefully and enter every detail exactly as it should appear in your release.

01

Open the official bot

Start the release request through the SUBMIT A RELEASE button in your PRYCOT. account. This opens the official PRYCOT. release bot in Telegram.

02

Enter your artist name

Write the artist name exactly as it should appear on digital platforms. Check spelling, capitalization and punctuation before continuing.

03

Enter the release title

Write the title exactly as it should appear on the release. Do not add information that does not belong to the official title.

04

Select the release type

Choose the correct type: Single, Maxi Single, EP or Album. Make sure the selected type matches the actual release.

05

Enter genre and release date

Enter the genre accurately. The release date must be written in the format YYYY-MM-DD.

06

Indicate explicit content

Select Yes if the release contains explicit content and No if it does not.

07

Enter the number of tracks

Enter the exact number of tracks that will be included in the release. The bot will then ask for each track title separately.

08

Enter track titles and send audio

For every track, enter the title exactly as it should appear and then send the corresponding audio file. Make sure each audio file belongs to the correct track.

09

Check the final summary

Before confirming, carefully check the complete summary shown by the bot. If anything is incorrect, do not confirm the request.

Important. All information must be entered without spelling mistakes, incorrect dates, wrong track titles or other inaccuracies. The release request is prepared from the information you provide in the bot. The request will be processed according to what was entered and confirmed in Telegram.
