PRYCOT. / TELEGRAM BOT GUIDETELEGRAM BOT GUIDE

Submit your release correctly. Every detail matters.

PRYCOT. uses an official Telegram bot to collect the release information and materials needed for submission. Open the bot from your PRYCOT. account and follow each step carefully.

01

Open the official bot

Sign in to your PRYCOT. account with Telegram and press SUBMIT A RELEASE. This opens the official PRYCOT. release bot and starts the release request.

02

Enter your artist name

Enter the artist name exactly as it should appear on digital platforms. Any language is allowed. Check spelling, capitalization and punctuation.

03

Enter the release title

Enter the release title exactly as it should appear on digital platforms. Any language is allowed. Check spelling, capitalization and punctuation.

04

Select the release type

Choose the correct type: Single, Maxi Single, EP or Album. Make sure the selected type matches the actual release.

05

Enter genre and release date

Enter the genre manually. Enter the release date in the format YYYY-MM-DD, for example 2026-10-15. The requested release date must be at least 9 calendar days after you submit the complete release request. For example, if you submit it on September 1, September 10 is the earliest available date; later dates are also possible.

06

Indicate explicit content

Select Yes if the release contains explicit content and No if it does not.

07

Enter the number of tracks

Enter a number from 1 to 20. The bot then asks for each track title separately.

08

Enter track titles and send audio

For every track, enter the title exactly as it should appear and then send the corresponding WAV file as an audio file or document. One audio file is submitted per track. The bot does not impose a separate bitrate, bit-depth, sample-rate or file-size restriction.

09

Send the artwork and review the request

After all audio files are received, send the release artwork as a JPG or PNG image or document. It must be square and exactly 3000 × 3000 px. Review the final summary carefully, then press CONFIRM, EDIT or CANCEL. EDIT discards the current request and starts the form again from the beginning; it does not edit individual fields.

Important. The information and files you enter in the bot are used to prepare the release request. After CONFIRM, the request is sent to the PRYCOT. admin and the release is added to your Dashboard. Your Dashboard then shows the release and its current status.

If an uploaded file is incorrect or the submission contains an inconsistency, PRYCOT may contact the user privately through Telegram to clarify or request the correct material.
